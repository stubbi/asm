# Code of conduct

asm welcomes contributors with different backgrounds, experience, and perspectives.
This policy applies to the project's issues, pull requests, discussions, and other spaces that its maintainers control.
It applies to maintainers and contributors alike.

## Expected conduct

- Treat other people with respect.
- Critique the work and explain your reasons.
- Allow room for questions, mistakes, and different levels of experience.
- Respect requests to stop unwanted contact.
- Protect other people's personal information.

Harassment, threats, discrimination, targeted insults, and unwanted sexual attention are unacceptable.
Sharing someone's private information without permission is unacceptable.
Retaliation against someone who reports a concern in good faith is unacceptable.
Technical disagreement is welcome when it remains respectful.

## Report a concern

For abusive GitHub content, use the content's **Report content** menu.
If GitHub offers **Report to repository admins**, you can send the concern to the project maintainers.
You can also report abuse to GitHub Support through [GitHub's reporting instructions][reporting].
That route is available for concerns involving a project maintainer.
GitHub assesses reports under its own policies.

Include links and enough context to explain the behavior.
Avoid publishing personal information or sensitive report details in an issue.
Use the [security policy](SECURITY.md) for software vulnerabilities.

## Response

Maintainers consider the available evidence, severity, and repeated behavior.
They can request a correction, remove content, restrict participation, or block an account from the project.
Serious conduct can require immediate action.
When possible, maintainers explain the action and the expected change in behavior.
They limit disclosure of report details to what the response requires.

A person can request reconsideration through the available reporting route.
New evidence and a clear explanation help that review.
asm currently has one listed owner and no separate moderation team.
This policy does not imply an independent appeal body or a guaranteed response time.

[reporting]: https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam
